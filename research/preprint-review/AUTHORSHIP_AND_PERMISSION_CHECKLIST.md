# Authorship, provenance, and release checklist

## Authorship
- [ ] Confirm the proposed author list with the professor/supervisor.
- [ ] Record each person's intellectual contribution to the research question, method, analysis, interpretation, and manuscript.
- [ ] Acknowledge data generation where appropriate; data provision alone does not automatically determine authorship.
- [ ] Add affiliations, author contributions, and any required acknowledgements.

## Data
- [ ] Record that the professor generated the dummy data specifically for the dissertation.
- [ ] Confirm in writing whether the dummy data may be reused or described in a public preprint.
- [ ] Verify that no confidential or identifiable information is present.
- [ ] Keep the professor-provided dataset and original coordinate/demographic files out of the public repository until permission and provenance are clear.

## Code and university conditions
- [ ] Confirm original code ownership, any university IP rules, and any third-party dependencies/licences.
- [ ] Confirm permission to redistribute project-derived geometry code.
- [ ] Separate newly written synthetic benchmark code from project-derived code.
- [ ] Add licence and citation information only after rights are established.

## Scientific readiness
- [ ] Verify all numbers against the raw and summary outputs.
- [ ] Check the cited references and full bibliographic metadata.
- [ ] Document literature search scope and date.
- [ ] Review the simulation assumptions and avoid overclaiming.
- [ ] State clearly that synthetic results do not establish clinical validity.
- [ ] Explain that the mask-level extension is not a direct test of the original hull/clipping pipeline.
- [ ] Treat threshold 0.5 as a tested baseline, not a universal optimum.

## Release
- [ ] Obtain supervisor/contributor feedback on scope and author list.
- [ ] Confirm university policy and any publication/IP requirements.
- [ ] Decide whether the repository should remain public during review.
- [ ] Only after all gates are cleared, prepare a public preprint and archived release.
